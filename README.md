# Резюме — Глеб (FantyI)

Сайт-резюме на React + Vite + GSAP. Должность: Разработчик Web и мультимедийных приложений.

```bash
npm install
npm run dev     # локальный запуск
npm run build   # сборка
```

## Разделы (по требованиям)

1. Фото
2. Личные данные — ФИО, возраст (дата рождения + лет), телефон, эл. почта
3. Цель резюме — искомая должность
4. Опыт работы — период, организация, должность, обязанности, достижения (практика)
5. Профессиональные навыки
6. Образование
7. Личные качества
8. Дополнительная информация
9. Сопроводительное письмо

Кнопка «Сохранить в PDF» печатает резюме в светлой теме.

## Что заполнить

- **Фото:** положите файл в `public/images/resume/photo.jpg` — он подставится сам.
- **Данные:** всё в `src/data/resume.js`. Замените всё, что в [квадратных скобках]
  (фамилия, отчество, практика, уровень английского). Если указать `birthDate`,
  возраст посчитается автоматически.
