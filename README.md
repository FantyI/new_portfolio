# Портфолио — Глеб (FantyI)

Сайт-портфолио на React + Vite + GSAP.

```bash
npm install
npm run dev     # локальный запуск
npm run build   # сборка
```

## Резюме и фото

Положите фотографию в `public/images/resume/photo.jpg` — она сразу появится в разделе «Резюме».
Пока файла нет, там показывается заглушка. Данные резюме (ФИО, дата рождения, практика и т.д.)
редактируются в объекте `resume` в начале файла `src/pages/Resume/Resume.jsx` — замените всё, что в [квадратных скобках].
